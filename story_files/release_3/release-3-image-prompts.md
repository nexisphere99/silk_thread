## TECHNICAL NOTES

1. **Resolution**: All images should be generated at minimum 2x the listed dimensions for retina/HiDPI displays, then downscaled and optimized to WebP format.

2. **Compression**: Target 200-400KB per background, 100-200KB per character portrait, 50-100KB per item image.

3. **Color grading**: All images should share a consistent color grade. Warm shadows, muted highlights, slight desaturation with amber/gold push in highlights. Think David Fincher cinematography (Bradford Young or Jeff Cronenweth).

4. **Consistency**: Victoria, Lena, Harper, and Martin should have consistent facial features across all their images. Use reference locks or face-consistent generation workflows.

5. **Content safety**: No explicit content in any image. Suggestiveness is achieved through composition, lighting, and implication (e.g., the panties on velvet, the hand on the pocket) rather than nudity or explicit imagery. The images serve an interactive fiction narrative and should feel literary, not pornographic.

6. **Fallback**: For the Twine game, backgrounds will be overlaid with a dark gradient (85-90% opacity) so text remains readable. Character portraits display in dialogue boxes or sidebars. Design images knowing they'll be partially obscured.
